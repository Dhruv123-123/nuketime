# Hunt 9 scoring rubric (applied by the synthesis, same for every candidate)

Hard filters first: no prospecting/exploration/drilling proving step; new company (not Terranox); company owns and realises the value (no software/service); credible path to a large company.

Score, max 10:
- P1 proving step (0-2): 2 = expensive (>= $100k per attempt) and base hit rate p <= 20% (lever cap 1/p >= 5x); 1 = expensive with p 20-50%, or cheap with low p; 0 = no uncertain step (pure arbitrage) or p > 50%.
- P2 signal (0-2): 2 = public, illegible at scale (scanned/PDF/unstructured/scattered), no legible summary field, incumbents pick by hand; 1 = partly structured or partly read already; 0 = a legible table, or already mined by ML incumbents.
- P3 unproven right (0-2): 2 = bought from fragmented owners who cannot read the record, cheap (<= 1% of proven value), transferable; 1 = buyable but owners price it or holders are concentrated; 0 = auctioned, first-come, or non-transferable.
- P4 proven state (0-2): 2 = R1 = proven value / unproven price >= 10x, liquid, named buyers, tradable before the full build; 1 = R1 2-10x or thin market; 0 = R1 < 2x or no buyer before the build.
- Ceiling (0-1): 1 = proven pool >= $10B across many assets; 0.5 = $1-10B; 0 = < $1B.
- Occupancy (0-1): 1 = nobody applies ML to this signal; 0.5 = incumbents without ML, or ML startups adjacent; 0 = occupied.

Report alongside: R1 (step-up multiple), proving cost per attempt, base hit rate p and lever cap 1/p, pool size, named incumbents, kill test.
